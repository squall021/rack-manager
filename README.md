# Rack Manager V2.4

機房機櫃視覺化管理工具，純前端版本，可直接部署在 GitHub Pages。

## 主要功能

- 多據點 / 多機房 / 多機櫃管理
- 6U～60U 自訂機櫃高度
- FRONT / REAR 切換
- 機架式、層板式、桌上型 / 塔式、外部設備
- Pointer Events 自訂拖曳與即時位置預覽
- 設備直接拉伸調整 U 高度與非機架式設備寬度
- U 位吸附與設備碰撞檢查
- 設備位置鎖定、複製、刪除、Undo / Redo
- 全域設備搜尋與目前機櫃設備篩選
- 設備總覽：跨據點 / 機房 / 機櫃搜尋與篩選
- 版本紀錄：自動備份、手動備份、還原舊版本
- 據點與機房新增、重新命名、刪除
- 新增 / 編輯機櫃時可直接指定據點與機房
- JSON 備份 / 還原
- Excel 設備清單匯出
- 單一機櫃 PNG / PDF 匯出
- 機房多機櫃配置 PNG / PDF 匯出

## V2.4 設備總覽

上方「設備總覽」可查看全部設備：

- 顯示目前據點、機房、機櫃與設備總數
- 搜尋設備名稱、IP、Hostname、型號、序號、資產編號等資料
- 依據點、機房、設備類型、狀態篩選
- 顯示設備所在機櫃、FRONT / REAR、U 位與狀態
- 點選資料列可直接跳到對應機櫃與設備位置

## V2.4 版本紀錄

上方「版本紀錄」提供瀏覽器本機資料保護：

- 第一次啟用 V2.4 會建立初始備份
- 真正的機櫃 / 設備資料變更後會自動建立版本
- 切換機櫃、FRONT / REAR、縮放比例等純介面操作不會建立版本
- 可手動建立備份
- 還原舊版本前會自動建立「還原前備份」
- 最多保留 20 個版本，並設有容量上限避免 LocalStorage 過度膨脹
- 可個別刪除不需要的版本

版本紀錄只存在目前瀏覽器。跨電腦或重大變更前，仍建議使用「匯出 → JSON 備份」。

## V2.3 機房配置匯出

從「匯出 → 機房配置圖…」可建立同一機房的多機櫃配置圖：

- 選擇據點與機房
- 勾選要輸出的機櫃
- 以滑鼠拖曳自訂機櫃順序
- 上移 / 下移按鈕作為排序備用操作
- 可將目前順序儲存為該機房的預設排列
- FRONT、REAR 或 FRONT + REAR
- 每頁 2 / 3 / 4 個機櫃
- A4 / A3
- 橫式 / 直式
- 可選擇是否顯示機櫃位置、設備型號、設備 IP
- PDF 自動分頁
- PNG 若超過一頁，會將頁面縱向排列成一張圖片

V2.3 已移除左側「移動機櫃」按鈕。機櫃若要轉移據點或機房，統一從「機櫃設定」修改歸屬；「據點管理」則負責據點與機房本身的新增、重新命名與刪除。

## 使用方式

直接開啟 `index.html` 即可使用。

若瀏覽器阻擋本機檔案載入 CDN，建議使用 VS Code Live Server，或部署到 GitHub Pages。

## GitHub Pages

1. Repository：`rack-manager`
2. GitHub → Settings → Pages
3. Source 選擇 `Deploy from a branch`
4. Branch 選擇 `main` / `(root)`
5. 儲存後即可使用

## 資料保存

目前資料主要儲存在瀏覽器 LocalStorage。正式使用前建議定期從「匯出 → JSON 備份」下載完整備份。

後續可改接 Google Sheets / Apps Script，支援多人共用與跨電腦使用。

## 外部套件

透過 CDN 載入：

- html2canvas：PNG / PDF 圖面擷取
- jsPDF：PDF 匯出
- SheetJS：Excel 匯出
